# Python Mini Projects 

A collection of beginner-friendly Python projects created to practice programming fundamentals and basic cybersecurity concepts.

##  Projects

###  Caesar Cipher
A simple text encryption and decryption program using the Caesar Cipher technique.

### Text Encryption
A basic Python program for encrypting and decrypting text.

###  Password Generator
Generates random passwords for better password security.

###  Password Strength Checker
Checks the strength of a password based on different criteria.

### Snake Water Gun
A simple command-line game implemented in Python.
